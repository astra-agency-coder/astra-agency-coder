# Curriculum — Design (intensive)

Objective: produce clean visual systems and assets with real files.

## Modules
1. **Visual system** — palette (hex), type scale, spacing, radius, key components.
2. **Layouts** — 3 page/slide layouts as images (Pillow or HTML->screenshot).
3. **Thumbnails** — 3 thumbnail concepts for real video/post topics, correct sizes.
4. **Brand kit** — logo lockup, color tokens, usage rules.
5. **Design review** — critique one asset against the system; list concrete fixes.

## Acceptance
Every asset is a real file (PNG/SVG) at correct dimensions, with the token sheet.
No "described design" — only produced design.
