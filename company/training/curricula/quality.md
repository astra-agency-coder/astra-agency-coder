# Curriculum — Quality

Objective: independently verify work so nothing ships unproven.

## Modules
1. **Acceptance discipline** — write acceptance criteria before inspecting.
2. **Reproduce** — reproduce the deliverable yourself from scratch.
3. **Break it** — edge cases, bad input, empty/missing files, wrong sizes.
4. **Security pass** — secrets, permissions, unsafe defaults.
5. **Verdict** — PASS/FAIL with exact reproduction steps and evidence.

## Rule
A deliverable passes only when every criterion is demonstrably met. Never
rubber-stamp; never mark untested work as passed.
