## 1. What works

1. **The numbers are actually measured, not typed.** `src/lib/facts.ts` shapes
   `src/data/facts.json` (generated by `tools/gen_facts.py`), and the hero reads
   `facts.readiness.passed`, `facts.repos.ok`, `facts.engine.passed`,
   `facts.roster.agents` (page.tsx 41–46). The Quality grid even renders the
   *unverified* state honestly (`t.quality.rows[].state === "blocked"` → red
   "needs credentials", page.tsx 229–235). Very few marketing pages do this.

2. **The CSS token layer is single-sourced and disciplined.** `@theme`
   (globals.css 9–35) defines 6 ink/line neutrals, 4 golds, bull/bear, fog/snow,
   and 3 font slots. Every surface, border, gradient and text colour in
   `globals.css` derives from those variables via `color-mix(in oklab, …)`.
   `--rail` (line 39) gives one responsive gutter used by `.shell` everywhere.

3. **RTL is engineered, not retrofitted.** `dir` is set on `<html>`
   (layout.tsx 62); the layout uses logical properties throughout
   (`padding-inline` 96, `inset: 0 0 auto 0` 237, `transform-origin: inline-start`
   266); the marquee reverses (177). Only two physical-direction classes exist in
   the whole app (page.tsx 198, 211) — see weakness 5.

4. **Motion budget is small and respects the user.** One reveal transition, one
   marquee, one pulse. All three are disabled under
   `prefers-reduced-motion: reduce` (globals.css 159–164). No parallax, no
   scroll-jacking, no autoplay. `ScrollProgress` is the only addition.

5. **Accessibility plumbing is present.** `.tap` guarantees ≥40px targets
   (globals.css 272–278), the timeframe control is a real
   `role="tablist"`/`role="tab"`/`aria-selected` group (CandleChart 56–70),
   decorative layers are `aria-hidden`, and `:focus-visible` is styled globally
   (66–70). The supplied `shots/audit.json` shows 0 overflow / 0 overlaps /
   0 small targets / 0 unlabelled SVG across 3 locales × 3 viewports.

## 2. What is weak

1. **The Arabic display type is an uncontrolled OS fallback — the single biggest
   brand defect.** `.display` (globals.css 102–107) and `.eyebrow` (109–115)
   declare only `var(--font-display)` / `var(--font-mono)`. IBM Plex Sans Arabic
   is loaded (layout.tsx 17–22) and applied **only to `body`** via
   `[dir="rtl"] body` (globals.css 59). CDP confirms the consequence on `/ar`:
   ```
   ar  h1            -> [('DejaVu Sans', 27), ('Fraunces', 4)]
   ar  h1 .gold-text -> [('DejaVu Sans', 16), ('Fraunces', 3)]
   ar  .eyebrow      -> [('DejaVu Sans', 22), ('JetBrains Mono', 15)]
   ar  h2            -> [('DejaVu Sans', 22), ('Fraunces', 4)]
   en  h1            -> [('Fraunces', 36)]
   ```
   So the Arabic headline and eyebrow render in **DejaVu Sans** — a font that is
   not part of this project and not in the design system — while `/en` and `/tr`
   render Fraunces. The Arabic site looks like a different product.

2. **With JavaScript off, the page is blank.** Every content block carries
   `.reveal`, which starts at `opacity: 0` (globals.css 151–156) and only becomes
   visible when `RevealObserver`'s IntersectionObserver adds `.in`. Measured with
   JS disabled: `reveal_total: 23, reveal_invisible: 23, h1_opacity: 0`. The
   comment on globals.css 150 ("visible without JS") is false. A company whose
   pitch is "every number is measured" ships a page that shows nothing if the
   bundle fails. There is no `<noscript>` fallback anywhere.

3. **The chart's price axis is both illegible and wrong.** In
   `CandleChart.tsx`:
   - `preserveAspectRatio="none"` (line 79) with `viewBox 0 0 1000 380` (75)
     stretched into `h-[300px] w-full` (76). At a 390px viewport the box is
     308×300 → x-scale **0.308**, y-scale **0.789**. The `fontSize="10"` axis
     labels (87) therefore render **3.1px wide × 7.9px tall** — squashed ~2.6×
     and unreadable. On desktop the same rule stretches them the other way
     (12.96px × 10px).
   - Axis label colour `#5a5f72` (87) on `--color-ink` is **3.19:1** contrast —
     fails WCAG AA (4.5:1) for text.
   - **Correctness bug:** gridlines are spaced over `H - PAD.t - PAD.b` (line 82)
     but the candles are mapped over `innerH = H - PAD.t - PAD.b - VH` (line 36,
     `VH = 64`). The two scales diverge: the bottom gridline sits at y=354 while
     `y(lo)` is at y=290, so **3 of the 5 price labels do not point at the price
     they claim.** The volume strip (129–145) introduced this.

4. **The chart is hard-coded English in a trilingual product, and mislabels its
   own data.** `aria-label="Timeframe"` (56), the tab text `k.toUpperCase()` (68),
   and the legend `{zones} zones` / `{liquidity} liquidity pools` (151–152) are
   literal English. The dictionaries already carry `t.platform.tabs` (h1/h4/d1),
   `t.platform.zones` and `t.platform.liquidity`, and none are used
   (page.tsx 126–131 passes only `label`). The aria-label also says
   `` `XAUUSD ${tf} candles, ${candles.length} bars` `` (78) while the series is
   sliced to the latest 101 of a longer capture — it doesn't say so.

5. **Two physical-direction classes break RTL alignment.** page.tsx 198
   (`text-right` on the "people" header) and 211 (`md:text-right` on headcount).
   In RTL these pin to the physical right, which is the *leading* edge, so the
   headcount collides with the repo column instead of aligning to the trailing
   edge. Every other alignment in the file is logical — this is an inconsistency,
   not a decision.

6. **There is no type scale — only per-component guesses, with a sub-10px floor.**
   Labels use six sizes and eleven tracking values:
   `0.6rem/0.16em` (page.tsx 341), `0.62rem/0.18em` (92, 196–198),
   `0.66rem/0.16em` (228), `0.7rem/0.14em` (306), `0.72rem/0.28em`
   (globals.css 111–112), `0.78rem` (94). Measured smallest text on the page:
   **9.28px** (SetupCard 112, `text-[0.58rem]`) and **9.6px** (page.tsx 341,
   `text-[0.6rem]`). Both are below a 10px legibility floor, and both sit at
   `--color-fog-dim` (4.56:1 on the panel background — barely AA).

7. **The gold italic headline is a synthesized fake.** page.tsx 71 applies
   `italic` to `.gold-text`, but Fraunces is loaded without an italic face:
   `layout.tsx 7–12` passes `axes: ["SOFT","WONK","opsz"]` and no
   `style: ["italic"]`. The built CSS contains **40 `@font-face` rules and zero
   italic faces** — all three Fraunces faces are `font-style: normal`, and no
   family has an italic. The only `italic` in the output is Tailwind's
   `.italic{font-style:italic}` utility, so the browser *synthesises* the slant
   (`font-synthesis: weight style small-caps`), which on a serif reads as cheap.
   On `/ar` that fake italic is applied to DejaVu Sans.

8. **Two sources of truth for the same metrics, already out of sync.**
   `heroMetrics` is driven by `facts.*` (page.tsx 41–46), but the Quality grid
   renders hand-typed strings from the dictionary (page.tsx 225 →
   `t.quality.rows`). The measured `facts.json` now reports
   `security: {passed: 25, total: 27, findings: 2}`, while the dictionaries still
   advertise `"27/27 · 0 open findings"` (en `metrics`) and the hero never shows
   the security number at all. The page can therefore display a typed 27/27 next
   to a measured 25/27. Half the fix is already done (facts-driven hero); the
   other half (typed dictionary numbers) contradicts it.

9. **`--color-bull` carries two unrelated meanings.** Green is used for market
   direction (LiveTick up arrow, up-candles) *and* for "verified / pass" status
   (page.tsx 231, 237). Likewise red `--color-bear` marks both down-candles and
   the "needs credentials" state — which is not an error, just unverified. One
   colour, two vocabularies, on the same screen.

10. **Section rhythm is flat.** Measured: the hero is `pt-36 pb-24 sm:pt-44`
    (page.tsx 65 → 176px top / 96px bottom at desktop), then *every* following
    section is exactly `py-24 sm:py-32` (128px). Six sections of identical
    weight means the flagship Platform section gets no more space than the
    footer-ish Quality grid, and the hero's 176px top padding is not derived from
    the fixed nav height, so it can drift under the nav.

## 3. Concrete fixes, ranked by impact

**1. Give Arabic its own display stack.** In `globals.css`, after line 115, add:

```css
[dir="rtl"] .display { font-family: var(--font-ar), var(--font-display), serif; letter-spacing: 0; }
[dir="rtl"] .eyebrow { font-family: var(--font-ar), var(--font-mono), sans-serif; letter-spacing: 0.14em; }
```

(Reset `letter-spacing`: negative tracking 106 is tuned for Latin and crushes
Arabic joins.) Verify with CDP that `/ar` `h1` reports IBM Plex Sans Arabic, not
DejaVu Sans.

**2. Make the page render without JavaScript.** In `src/app/[lang]/layout.tsx`,
inside `<body>` (before line 66's children), add:

```tsx
<noscript>
  <style>{`.reveal{opacity:1!important;transform:none!important}`}</style>
</noscript>
```

This is the minimal honest fix. If you want the content-first approach, invert
globals.css 151–156 instead: default `.reveal { opacity: 1; transform: none; }`
and move the hidden state behind `.js .reveal`, adding
`document.documentElement.classList.add("js")` in `RevealObserver`. Either way,
re-test with JS disabled and assert `reveal_invisible === 0`.

**3. Stop the chart from distorting.** In `CandleChart.tsx` line 79 change
`preserveAspectRatio="none"` → `preserveAspectRatio="xMidYMid meet"`, and line 76
change `className="h-[300px] w-full sm:h-[380px]"` →
`className="h-auto w-full"`. The viewBox ratio (1000:380) then drives height and
the axis type is never squashed.

**4. Fix the axis/candle scale mismatch (correctness).** In `CandleChart.tsx`
line 82 change

```tsx
const yy = PAD.t + (i / gridLines) * (H - PAD.t - PAD.b);
```
to
```tsx
const yy = PAD.t + (i / gridLines) * innerH;
```

so gridlines and price labels share the candle scale (`innerH` already accounts
for the volume strip).

**5. Raise the axis label contrast and stop hard-coding the palette.**
In `globals.css` add:

```css
.candle-up   { fill: var(--color-bull); }
.candle-down { fill: var(--color-bear); }
.chart-grid  { stroke: var(--color-line); }
.chart-axis  { fill: var(--color-fog); font-family: var(--font-mono); font-size: 11px; }
.chart-last  { stroke: var(--color-gold-bright); }
```

Then in `CandleChart.tsx` replace the literals: line 86 `stroke="#23232f"` →
`className="chart-grid"`; line 87 `fill="#5a5f72" fontSize="10"
fontFamily="monospace"` → `className="chart-axis"`; lines 97/141
`#16c79a/#ff4d6d` → `chart-up`/`chart-down`; line 123 `stroke="#e8c766"` →
`className="chart-last"`. Also delete the redundant ternary on line 110
(`fill={up ? col : col}` → `fill={col}`).

**6. Create one label utility and kill the sub-10px sizes.** In `globals.css`
add:

```css
.label {
  font-family: var(--font-mono);
  font-size: 0.7rem;          /* 11.2px floor */
  letter-spacing: 0.16em;
  text-transform: uppercase;
  color: var(--color-fog-dim);
}
```

Then replace the ad-hoc `mono text-[0.XXrem] tracking-[0.XXem] uppercase`
combinations at page.tsx 92, 196–198, 228, 230, 261, 306, 341 and SetupCard 112
with `label`. That removes the 9.28px/9.6px text and the six tracking values at
once.

**7. Localise the chart.** Add props to `CandleChart` for the tab labels and the
two legend strings, pass them from page.tsx 126–131
(`tabs={t.platform.tabs}`, `zonesLabel={t.platform.zones}`,
`liquidityLabel={t.platform.liquidity}`), and use them at CandleChart 56
(`aria-label`), 68 (tab text — use `tabs.h1/h4/d1` instead of `toUpperCase()`)
and 151–152. Change the aria-label on line 78 to name the window explicitly,
e.g. `` `XAUUSD ${tf}, latest ${candles.length} bars` ``.

**8. Fix the RTL alignment leaks.** page.tsx 198 `text-right` → `text-end`;
page.tsx 211 `md:text-right` → `md:text-end`.

**9. Load the real italic, or drop it.** In `layout.tsx` 7–12 add
`style: ["italic"]` to the Fraunces config so `.gold-text` (page.tsx 71) has a
genuine italic. If you don't want a second font file, remove `italic` from
page.tsx 71 — but do not ship a synthesized oblique on the hero.

**10. Drive the Quality grid from `facts`, not from typed strings.**
Replace `t.quality.rows` (page.tsx 225) with a list built from
`facts.readiness/engine/api/security/repos`, deriving `state` from
`facts.*.status`. Then delete the now-dead `value`/`state` fields from the
`quality.rows` objects in `dictionaries.ts`. This removes the 27/27-vs-25/27
contradiction (weakness 8) by construction.

**11. Add a time axis to the chart.** Under the plot (before line 148) render
three `c.t` labels — first, middle, last candle — as `.label` text, so a reader
can see what period the bars cover. Right now the x-axis is unlabelled.

**12. Give the sections a rhythm.** In `page.tsx` line 65 change the hero to
`pt-40 pb-28 sm:pt-52` and in line 115 change the Platform section to
`py-28 sm:py-40`, leaving the utility sections at `py-24 sm:py-32`. The flagship
product then gets visibly more air than the Quality table.

## 4. Typography, spacing, colour and motion notes

**Typography.** Three families are loaded and mapped correctly
(`--font-display` Fraunces, `--font-sans` Inter, `--font-mono` JetBrains Mono,
plus `--font-ar` IBM Plex Sans Arabic; layout.tsx 7–22, globals.css 32–34).
The *wiring* is right; the *application* is not (fix 1). Two real type bugs:
`line-height: 0.98` on `.display` (globals.css 105) is below 1, so any
multi-line display heading has touching ascender/descender boxes — measured
`lh/fs = 0.980` on the 99.2px `h1`, i.e. a 97.2px line box for 99.2px text.
Raise it to `1.02` for Latin and `1.25` for Arabic (Arabic needs more, since it
has deep descenders and no ascender gap). And the Turkish subsets are fine —
Fraunces covers `ı İ ğ Ğ ş Ş ç Ç ö ü Ö Ü` in its `U+100-2BA` / `U+??` ranges;
do **not** "fix" Turkish fonts, there is no bug there.

**Spacing.** One gutter token (`--rail`, globals.css 39) is applied consistently
through `.shell` (96) — good. But vertical rhythm is uniform-to-a-fault
(fix 12), and the hero's top padding is a magic number (`pt-36`, 65) unrelated
to the fixed nav height (`.nav` is `position: fixed`, globals.css 235–241), so
content can slide under the bar at intermediate widths. Derive it from a
`--nav-h` token instead.

**Colour.** The palette is coherent and dark-first; the contrast audit is mostly
clean: `snow` 17.8:1, `fog` 9.1:1, `gold-bright` 12.3:1, `bull` 9.3:1,
`bear` 6.3:1 on `--color-ink`. Three problems: (a) `--color-fog-dim` is only
4.87:1 on ink and **4.56:1 on the `ink-3` panels** — it is used for most small
labels, so it is simultaneously the smallest and the lowest-contrast text;
(b) the chart's `#5a5f72` is 3.19:1 and fails outright (fix 5);
(c) `--color-line` is 1.30:1 against `--color-ink`, so 1px panel borders are
nearly invisible — the `gap-px` hairline grids rely on this and read as mush at
a glance. If the borders are meant to be seen, lift `--color-line` toward
`#2a2a38`; if they are not, stop spending `gap-px` on them.

**Motion.** The budget is disciplined (one reveal, one marquee, one pulse) and
correctly disabled under `prefers-reduced-motion` (159–164). Two notes:
`.reveal` transitions `opacity` and `transform` with
`cubic-bezier(0.2, 0.7, 0.2, 1)` at 0.7s and staggers via `--d` — that is good,
but the `translateY(18px)` (153) is applied to every `.reveal`, so the whole
page performs the same 18px slide a dozen times; vary or drop it for section
heads and keep it for cards. The marquee duplication (`Array.from({length: 2})`,
page.tsx 104) is correct for a seamless loop, but the `38s` duration (175) is
arbitrary and never tied to the track width (measured 3102px); if you change the
item list the speed silently changes. It is already `aria-hidden`, which is
correct.
