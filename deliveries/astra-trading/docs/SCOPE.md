# Astra Trading — Product Scope (v2, world-class rebuild)

**Owner goal:** a genuinely sellable, world-class gold (XAU/USD) analysis product.
Not a demo. Not a mockup. Something a paying customer would renew.

## Product in one line
An AI analyst that publishes **rule-based, auditable XAU/USD scenarios** with a
**public, honest track record** — and never pretends to be more than that.

## Non-negotiables
1. **Honesty.** No fabricated wins, no fake testimonials, no "AI that prints money".
2. **Auditable method.** Every level/zone has a published, reproducible rule.
3. **Measured record.** Every published setup is scored by the evaluator; the
   public record is computed from the DB, never typed by hand.
4. **Design excellence.** One design system, trilingual (ar/en/tr), RTL-correct.
5. **Reliability.** Runs 24/7, self-heals, secrets never in files.

## Success criteria (measurable)
| # | Criterion | Target |
|---|---|---|
| 1 | Analysis method documented | written + versioned |
| 2 | Backtest on real history | >= 2000 bars, honest stats |
| 3 | Design system | tokens + >= 20 components |
| 4 | Trilingual + RTL | 3 locales, no overflow |
| 5 | End-to-end user journey | open → see setup → pay → activated |
| 6 | Uptime | deployed 24/7, monitored |
| 7 | Tests | engine, API, UI, e2e all green |

## Out of scope (this phase)
- Executing trades, holding funds, promising returns.
- Anything requiring the Owner's private keys.
