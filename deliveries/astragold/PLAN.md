## 1. الرؤية بجملة واحدة

> **"AstraGold يحوّل شارت الذهب إلى قرار واضح: وين الدعم والمقاومة، وين السيولة، وما هو السيناريو المنطقي — بالأرقام لا بالإحساس."**

---

## 2. المشكلة والسوق

**المشكلة:** متداول الذهب (XAU/USD):
- يرسم الدعوم والمقاومات يدوياً → بطيء وغير ثابت.
- لا يعرف أين تتركّز السيولة (equal highs/lows، قمم وقيعان الجلسات، الأرقام المستديرة).
- يتداول بالحدس بلا خطة دخول/خروج/وقف واضحة.
- مشتّت بين عشرات المؤشرات بلا خلاصة.

**السوق:** الذهب من أكثر الأدوات تداولاً عالمياً. المتداول العربي (الخليج/مصر/الشام/تركيا) شريحة كبيرة، والمنتجات المتخصصة **بالعربي** قليلة → فرصة تمييز.

**المنافسون (أسعار حقيقية تحققت منها):**
- TradeZella (journal): $29–99/شهر · $288–399/سنة
- Edgewonk (journal): $169–197 لمرة واحدة
- مؤشرات TradingView مدفوعة: $49–199
- ⇒ السوق **متعوّد على الدفع**. تمييزنا: تخصص ذهب + عربي + شفافية.

### 4.2 v2 (تحسينات قريبة)
- **سجل أداء شفّاف** (Track Record) للسسيناريوهات — backtest + سجل أمامي حقيقي.
- تنبيهات (بريد/تليجرام) عند ملامسة السعر لمنطقة.
- تقرير أسبوعي تلقائي.
- مجلة صفقات المستخدم + إحصاءاته (win rate, R, expectancy).
- دعم لغتين (عربي/إنجليزي).

### 4.3 v3 (توسّع لاحق)
- أصول إضافية (فضة، مؤشرات، فوركس) — **بعد إثبات الذهب**.
- واجهة API + ربط TradingView/MT5.
- مجتمع + غرفة نقاش.

## 5. ⚠️ صياغة "الصفقات" — قرار أخلاقي وقانوني حاسم

المالك طلب "تطبيق يعطي صفقات". هذا **حسّاس**: تقديم "توصيات" قد يُصنّف نصيحة مالية/استثمارية ويحمّلنا مسؤولية قانونية، ويصطدم بثقة السوق.

**الموقف المعتمد (مقترح للاعتماد من المالك):**

| ✅ نعم | ❌ لا |
|---|---|
| **سيناريوهات تحليلية (Setups)** بقواعد معلنة: منطقة + دخول + وقف + هدف + R:R | "توصيات" أو "إشارات" بلغة الجزم |
| سجل أداء **شفّاف وقابل للتدقيق** (backtest + سجل أمامي) مع ذكر عيوبه | وعود بأرباح أو نسب نجاح مضمونة |
| إفصاح مخاطر واضح على كل شاشة | إخفاء أن هذا تحليل تقني لا نصيحة |
| المستخدم يقرر — نحن نعرض الاحتمالات | التداول نيابة عن المستخدم أو ربط حساب/سحب أموال |

**الصياغة الرسمية على المنتج:** «تحليل تقني تعليمي — ليس نصيحة استثمارية. التداول يحمل مخاطر خسارة رأس المال.»

هذا يحمينا قانونياً وسمعياً ويفرّقنا عن 90% من السوق القائم على الوعود الكاذبة.

## 7. المعمارية التقنية (Architecture)

```
┌───────────────────────────────────────────────────────────┐
│  الواجهة  Next.js/React  →  Vercel / Cloudflare Pages      │  ← مجاني، دائم
│  الشارت   lightweight-charts (مكتبة TradingView مفتوحة)    │  ← مجاني
├───────────────────────────────────────────────────────────┤
│  محرّك التحليل  Python FastAPI (ATR, S/R, سيولة, setups)   │  ← كود نملكه
│  عامل البيانات  worker يجلب الشموع + يحسب المناطق + كاش    │
│  المهام المجدولة cron: تحديث البيانات + إرسال التنبيهات     │
├───────────────────────────────────────────────────────────┤
│  البيانات  Supabase Postgres (مستخدمون، اشتراكات، شموع،    │
│            سيناريوهات، سجل أداء) + Auth + RLS               │  ← عندنا حساب ✅
├───────────────────────────────────────────────────────────┤
│  الدفع  Stripe (بطاقات) + تحقق on-chain USDT TRC20         │
│         (عبر TronGrid API — نتحقق بأنفسنا)                  │
├───────────────────────────────────────────────────────────┤
│  الكود + CI/CD  GitHub (عندنا) ✅                           │
└───────────────────────────────────────────────────────────┘
```

**لماذا هذا الستاك؟** أرخص وأسرع: لا سيرفرات نديرها، ولا تكلفة بنية تحتية بالبداية. كل شيء قابل للترقية لاحقاً.

**⚠️ قيد بيئة مهم:** سيرفر OpenHands مؤقّت → لا نستضيف منه. نبني الكود هنا وننشر على Vercel/Cloudflare.

## 9. تجربة المستخدم (UX flow مختصر)

`تسجيل (بريد/Google)` → `أسبوع مجاني` → `لوحة الذهب`:
شارت + طبقات (دعم/مقاومة/سيولة) → بطاقة سيناريو (اتجاه، دخول، وقف، أهداف، R:R) → حاسبة مخاطرة → ملخص يومي بالعربي → تنبيهات.

## 12. الامتثال والقانون

- إفصاح مخاطر على كل شاشة + عند التسجيل (موافقة صريحة).
- شروط استخدام + سياسة خصوصية.
- **لا** نصيحة استثمارية، **لا** وعود أرباح، **لا** إدارة أموال.
- **لا** تشغيل آلي لصفقات المستخدم.
- 18+ فقط.
- تحديد الكيان القانوني/الاختصاص → **يحتاج قرار المالك**.

## 13. مؤشرات النجاح (KPIs)

- معدل تحويل التجربة → مدفوع (هدف مبدئي ≥ 5%).
- MRR (الإيراد الشهري المتكرر).
- Churn شهري.
- DAU/WAU.
- **دقة السيناريوهات** — تُقاس بصدق وتُنشر (لا تجميل).

## 14. ما نحتاجه من المالك (NEEDS OWNER ACTION)

1. ⏳ **تفاصيل مصدر الشموع** (رابط/API/تنسيق/رمز/فريم/حدود) — **حاجب أساسي**.
2. ⏳ **Supabase**: إنشاء مشروع + URL + مفاتيح (anon/service).
3. ⏳ **Vercel أو Cloudflare**: حساب + Token (استضافة دائمة).
4. ⏳ **الدفع**: Stripe (يحتاج كيان/بطاقة) أو تأكيد **كريبتو فقط** (USDT TRC20 متوفر ✅).
5. ⏳ **Domain** (اختياري لكنه يعطي ثقة).
6. ⏳ **الكيان القانوني/الاختصاص** (لشروط الاستخدام).
7. ✅ قرار: هل نعتمد **صياغة "السيناريوهات" الأخلاقية** في القسم 5؟
